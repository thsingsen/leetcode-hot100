# LeetCode Hot 100 · Python 刷题看板

> 在线使用：<https://thsingsen.github.io/leetcode-hot100/>

一个单文件的刷题进度看板，覆盖 LeetCode 官方「热题 100」。打开就能用，不需要账号、不需要后端，进度存在你自己的浏览器里。

## 功能

- **按分类追踪进度**：17 个分类，每个分类一条独立进度条，满分类会高亮
- **三态打卡**：点状态标签循环切换 `未刷 → 已刷 → 需复习`，比「刷完/没刷完」更贴近真实复习节奏
- **建议下一题**：按「先补短板、再啃困难题」的顺序推荐（子串 → 链表 → 栈/堆 → 124/51/4/32）
- **搜索**：题号、中文题名、英文 slug（如 `queen`、`lru`）、分类名都能搜
- **筛选与排序**：状态 / 难度 / 分类 / 题单顺序·题号·难度
- **深浅色**：跟随系统，也可以手动切换，选择会记住
- **进度可带走**：复制分享链接（进度编码在 URL 里）、导出/导入 JSON 备份
- **移动端可用**：响应式布局，手机上可以「添加到主屏幕」当小应用
- **快捷键**：`/` 搜索、`Esc` 清空、`T` 换主题、`E` 进度管理、`?` 帮助

## 本地打开

直接双击 `index.html` 即可，没有任何构建步骤，也没有外部依赖（字体图标全是内联 SVG）。

## 数据说明

题目清单对齐 LeetCode 官方 Hot 100（快照日期 2026-09-08），共 100 题、17 个分类。
数据以数组形式内联在 `index.html` 顶部：

```
[分类, 题号, 题名, 难度(1易/2中/3难), 初始状态(1已刷/0未刷/2需复习), 备注, leetcode slug]
```

想改题目或备注，直接编辑这一段即可。
